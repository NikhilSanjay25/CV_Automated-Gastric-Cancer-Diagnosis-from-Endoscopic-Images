# Automated Gastric Cancer Diagnosis from Endoscopic Images

A cascaded spatio-temporal framework (MobileNetV2 gate → ResNet-50 features → Bi-LSTM), compared against 9 baselines on 4 public databases.

**Authors:** Nikhil Sanjay (BL.EN.U4CSE23239), Andrew Tom Mathew (BL.EN.U4CSE23269). **Guide:** Dr. Tripty Singh, Amrita School of Computing, Bengaluru.

## What is in this folder

| Path | Contents |
|---|---|
| `paper/main.tex` | IEEE-format paper (IEEEtran). `paper/main.pdf` is the compiled version |
| `paper/figures/` | All figures (PDF for LaTeX, PNG for slides), generated by `src/make_figures.py` |
| `paper/tables/` | All result tables and `macros.tex` (every number quoted in the text), generated by `src/make_tables.py` |
| `src/` | All code (see below) |
| `results/` | Raw outputs: per-model JSON metrics, test probabilities (`*_test.npz`), robustness, efficiency, Grad-CAM |
| `checkpoints/` | Trained weights |
| `logs/` | Training logs |
| `run_all.sh` | Reproduces everything end-to-end |

## Code

| File | Purpose |
|---|---|
| `scripts/download_data.py` | Downloads Kvasir v2 (official Simula host), HyperKvasir, Kvasir-SEG (from HyperKvasir), GastroVision and CVC-ClinicDB |
| `src/prepare_data.py` | Stratified 70/15/15 split; images cached once at 224×224 (bicubic) |
| `src/common.py` | GPU augmentation, artifact simulation, synthetic 5-frame clips, focal loss, the 10 metrics |
| `src/models.py` | 8 torchvision baselines and the Bi-LSTM + temporal-attention head |
| `src/train_cnn.py` | Fine-tuning: AdamW, differential LR, warm-up + cosine schedule, CE or focal loss |
| `src/classical.py` | SIFT bag-of-visual-words + HSV + LBP features → RBF-SVM baseline |
| `src/proposed.py` | Bi-LSTM training, τ selection, cascade, ablations, artifact tests, latency |
| `src/evaluate.py` | Baselines under artifacts, efficiency (params/GMACs/FPS), cross-database test |
| `src/gradcam.py` | Grad-CAM and its localisation scores against expert polyp masks |
| `src/make_figures.py`, `src/make_tables.py` | Paper figures and LaTeX tables |

## Databases (4)

Kvasir v2 (8,000 images, 8 classes; the main benchmark), GastroVision (multi-class, upper and lower GI), Kvasir-SEG and CVC-ClinicDB (polyp masks; used only for external testing and Grad-CAM localisation). Classes with fewer than 30 images are dropped.

## Baselines (9)

SIFT-BoVW+SVM, AlexNet, VGG-16, GoogLeNet, ResNet-50, DenseNet-121, MobileNetV2, EfficientNet-B0, ViT-B/16. All CNN/ViT baselines are ImageNet-pretrained and get the same data, augmentation, optimiser and epoch budget.

## Performance evaluators

Accuracy, Precision, Recall (sensitivity), F1, Specificity, Balanced accuracy, MCC, Cohen's κ, ROC-AUC, plus efficiency (parameters, GMACs, FPS) and explainability (pointing game, energy-in-mask, IoU).

## Reproduce

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run_all.sh            # about 4 h on an Apple M-series GPU
cd paper && tectonic main.tex
```
